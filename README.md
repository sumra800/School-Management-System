# School Management System

Welcome to the **School Management System** project! This is a comprehensive web-based application designed to streamline and automate the daily administrative and academic operations of a school.

## 🚀 Features

The system provides a robust Admin Portal with the following core modules:

*   **Class Management**: Easily add new classes and manage class fee structures.
*   **Subject Management**: Maintain a catalog of subjects offered by the school.
*   **Teacher Management**: Register new teachers, assign subjects to teachers, and manage school expenses related to staff.
*   **Student Management**: Enroll new students and track detailed student records and their attendance.
*   **Examination Management**: Record and manage exam marks, and view detailed marks reports for students.
*   **Attendance Tracking**: Manage employee/teacher daily attendance and view attendance history.

## 🛠️ Technology Stack

This application is built using the Microsoft .NET ecosystem and standard web technologies:

*   **Backend framework**: ASP.NET Web Forms
*   **Programming Language**: C#
*   **Framework Version**: .NET Framework 4.7.2
*   **Frontend**: HTML, CSS, JavaScript
*   **Libraries & UI**: Bootstrap 4.6.0, jQuery 3.0.0, FontAwesome for icons

## 📂 Project Structure

*   `Admin/`: Contains the protected administrative web pages (`.aspx`) and the Master Page (`AdminMaster.Master`) defining the layout and sidebar menu.
*   `App_Data/`: Standard ASP.NET folder for local database files.
*   `Content/`: Static CSS styles and Bootstrap stylesheets.
*   `Scripts/`: JavaScript functional files and library dependencies (jQuery, Popper.js).
*   `images/`: Stores assets like background graphics and logos.
*   `Models/`: Contains the data models representing the business logic.

## ⚙️ Getting Started

To run this project locally, follow these steps:

1.  **Prerequisites**: Ensure you have [Visual Studio](https://visualstudio.microsoft.com/) installed with the **ASP.NET and web development** workload.
2.  **Open the Solution**: Double-click the `School Management System.sln` file to open the project in Visual Studio.
3.  **Restore Packages**: Visual Studio should automatically restore the required NuGet packages defined in `packages.config`. If not, right-click the solution and select "Restore NuGet Packages".
4.  **Run the Application**: Press `F5` or click the "Start" button in Visual Studio to build and launch the application in your default web browser.
